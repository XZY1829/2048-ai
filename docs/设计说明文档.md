# 纯 C++ 2048 移动网页游戏 + AI 冲分助手 — 设计说明文档

## 1. 项目概述

### 1.1 目标

**100% 纯 C++** 实现一个可在手机浏览器中打开的 2048 游戏，内置 AI 冲分助手。通过 Emscripten 编译为 WebAssembly，无需写一行 JavaScript。

### 1.2 核心体验

- **纯 C++ 全栈**：游戏逻辑、渲染、输入、AI 全部手搓
- **手机浏览器即玩**：URL 直达，滑动手势操控
- **AI 冲分**：一键开启 Expectimax 自动冲分 / 实时提示最优方向
- **跨平台**：同一份代码编译桌面 Native（调试）和 Web（部署）

### 1.3 技术选型

| 维度 | 选择 | 理由 |
|------|------|------|
| 语言 | C++17 | 纯 C++，无 JS |
| 渲染 | SDL2 + SDL2_ttf | 跨平台 2D，Emscripten 内置 port |

## 2. 游戏核心逻辑

### 2.1 Bitboard 棋盘

`uint64_t` 存储 4×4 棋盘，每个 cell 用 4 bit（存 log2 值，0=空，1=2，2=4 …… 15=32768）。

#### 为什么 4 bit 够用？

| 位宽 | 可表示范围 | 最大 tile | 说明 |
|------|-----------|-----------|------|
| 4 bit | 0~15 | 2^15 = 32768 | 当前方案 |
| 5 bit | 0~31 | 2^31 (远超需要) | 进阶方案 |

**选择 4 bit 的理由：**

1. **完美对齐** — 4 bit × 16 格 = 64 bit，刚好一个 `uint64_t`，无浪费
2. **查表大小合理** — 一行 4 个 nybble = 16 bit = 65536 种状态，表大小可控
3. **覆盖实际上限** — Expectimax (depth 5-6) 实际能冲到的极限约为 16384~32768，4 bit 完全覆盖
4. **业界标杆验证** — nneonneo/2048-ai（最知名的 C++ 2048 AI）就是 4 bit 方案

**何时需要升级到 5 bit：**

- 只有 TD-Learning (N-tuple Network) 这类训练型 AI 才有可能把 tile 推到 **65536**（log2=16，超出 4 bit）
- 此时需要 5 bit/cell → 80 bit 总宽 → 用 `__uint128_t` 或拆为两个 `uint64_t`
- 查表规模也需扩大到 2^20（100 万项），内存占用显著增加

**本项目结论：4 bit 方案足够，先做到极致；后续如加入 TD-Learning 再升级位宽。**

```cpp
using board_t = uint64_t;

inline int get_tile(board_t b, int r, int c) {
    int shift = ((3 - r) * 4 + (3 - c)) * 4;
    int power = (b >> shift) & 0xF;
    return power ? (1 << power) : 0;
}

inline uint16_t get_row(board_t b, int r) {
    return (b >> ((3 - r) * 16)) & 0xFFFF;
}
```

### 2.2 预计算查找表（65536 项）

#### 核心思想

一行有 4 个 nybble，每个 0~15，共 16^4 = 65536 种可能的行状态。**在程序启动时把所有行状态的移动结果、合并得分、启发式评估全部预计算好存到数组里**，运行时直接查表，O(1)。

#### 表的定义

```cpp
static uint16_t move_left_table[65536];   // row → 向左移动后的 row
static uint16_t move_right_table[65536];  // row → 向右移动后的 row
static int      score_table[65536];       // row → 该行向左移动产生的合并得分
static float    heur_table[65536];        // row → 该行的启发式评估贡献值
```

内存占用：`65536 × (2+2+4+4) = 768 KB`，完全可接受。

#### 初始化逻辑（向左移动模拟）

以行 `[4, 0, 4, 2]`（即 tile 值 16, 空, 16, 4）为例，向左移动：

```
Step 1 - 压缩（去零靠左）:  [4, 4, 2, 0]
Step 2 - 合并（相邻同值）:  [5, 2, 0, 0]  (4+4→5，即 16+16=32，得分32)
Step 3 - 结果编码:           0x5200
```

完整实现：

```cpp
void init_tables() {
    for (unsigned row = 0; row < 65536; row++) {
        // === 解码行为 4 个 nybble ===
        int tiles[4] = {
            (row >> 12) & 0xF,  // 最左
            (row >>  8) & 0xF,
            (row >>  4) & 0xF,
            (row >>  0) & 0xF   // 最右
        };

        // === 模拟向左移动 ===
        // Step 1: 压缩（非零值向左靠拢）
        int compressed[4] = {0, 0, 0, 0};
        int pos = 0;
        for (int i = 0; i < 4; i++) {
            if (tiles[i] != 0)
                compressed[pos++] = tiles[i];
        }

        // Step 2: 合并（相邻相同值合并，每对只合并一次）
        int score = 0;
        for (int i = 0; i < 3; i++) {
            if (compressed[i] != 0 && compressed[i] == compressed[i + 1]) {
                compressed[i]++;                    // log2 值 +1 = 值翻倍
                score += (1 << compressed[i]);      // 合并得分 = 合并后的实际值
                // 后面的值前移
                for (int j = i + 1; j < 3; j++)
                    compressed[j] = compressed[j + 1];
                compressed[3] = 0;
            }
        }

        // === 编码回 16-bit row ===
        uint16_t result = (compressed[0] << 12) | (compressed[1] << 8) |
                          (compressed[2] <<  4) | compressed[3];

        move_left_table[row] = result;
        score_table[row] = score;

        // === 右移表：翻转行 → 左移 → 翻转回来 ===
        uint16_t rev_row = ((row & 0xF) << 12) | (((row >> 4) & 0xF) << 8) |
                           (((row >> 8) & 0xF) << 4) | ((row >> 12) & 0xF);
        uint16_t rev_result = move_left_table[rev_row];
        move_right_table[row] = ((rev_result & 0xF) << 12) | (((rev_result >> 4) & 0xF) << 8) |
                                (((rev_result >> 8) & 0xF) << 4) | ((rev_result >> 12) & 0xF);

        // === 启发式评估（详见 AI 章节）===
        heur_table[row] = compute_row_heuristic(compressed);
    }
}
```

#### 一个完整的查表示例

```
原始行:   [2, 2, 0, 4]  → 编码 = 0x2204
                                    ↓ 查 move_left_table[0x2204]
移动结果: [3, 4, 0, 0]  → 编码 = 0x3400
合并得分: score_table[0x2204] = 8 (因为 2+2=4, 即 2^3=8)

含义: tile 4,4 合并成 8；tile 16 不动。
```

#### 为什么右移不需要单独模拟？

```
右移 [A,B,C,D] = 翻转 [D,C,B,A] → 左移 → 翻转结果
```

这样只需要实现一次左移逻辑，右移通过翻转复用。上/下移动同理，通过**转置**复用。

### 2.3 移动操作

#### 左移：逐行查表

整个 board 的左移 = 对 4 行分别查表，O(1) × 4 = O(1)。

```cpp
board_t move_left(board_t b) {
    board_t result = 0;
    result |= (board_t)move_left_table[(b >> 48) & 0xFFFF] << 48;  // row 0
    result |= (board_t)move_left_table[(b >> 32) & 0xFFFF] << 32;  // row 1
    result |= (board_t)move_left_table[(b >> 16) & 0xFFFF] << 16;  // row 2
    result |= (board_t)move_left_table[(b >>  0) & 0xFFFF];        // row 3
    return result;
}

board_t move_right(board_t b) {
    board_t result = 0;
    result |= (board_t)move_right_table[(b >> 48) & 0xFFFF] << 48;
    result |= (board_t)move_right_table[(b >> 32) & 0xFFFF] << 32;
    result |= (board_t)move_right_table[(b >> 16) & 0xFFFF] << 16;
    result |= (board_t)move_right_table[(b >>  0) & 0xFFFF];
    return result;
}
```

#### 上/下移动：转置 → 行移动 → 转置回来

列操作 = 行操作的转置版本。核心是实现 board 转置。

```cpp
board_t transpose(board_t b) {
    // 将 board 的行列互换
    // 原始布局:      转置后:
    //  row0            col0 col1 col2 col3
    //  row1     →      变为四行
    //  row2
    //  row3
    
    board_t t = 0;
    for (int r = 0; r < 4; r++) {
        for (int c = 0; c < 4; c++) {
            int src_shift = ((3 - r) * 4 + (3 - c)) * 4;
            int dst_shift = ((3 - c) * 4 + (3 - r)) * 4;
            t |= ((b >> src_shift) & 0xFULL) << dst_shift;
        }
    }
    return t;
}

// 也可用更高效的位操作版本（交换对角线上的 nybble 对）
board_t transpose_fast(board_t b) {
    board_t a1 = b & 0xF0F00F0FF0F00F0FULL;
    board_t a2 = b & 0x0000F0F00000F0F0ULL;
    board_t a3 = b & 0x0F0F00000F0F0000ULL;
    return a1 | (a2 << 12) | (a3 >> 12);
}

board_t move_up(board_t b) {
    return transpose(move_left(transpose(b)));
}

board_t move_down(board_t b) {
    return transpose(move_right(transpose(b)));
}
```

#### 合并得分获取

```cpp
int get_move_score(board_t before, board_t after, int direction) {
    // 以左移为例，对每行查 score_table
    int total = 0;
    if (direction == LEFT || direction == RIGHT) {
        for (int i = 0; i < 4; i++) {
            uint16_t row = (before >> (i * 16)) & 0xFFFF;
            total += score_table[row];
        }
    } else {
        // 上下移动：先转置再逐行查
        board_t tb = transpose(before);
        for (int i = 0; i < 4; i++) {
            uint16_t row = (tb >> (i * 16)) & 0xFFFF;
            total += score_table[row];
        }
    }
    return total;
}
```

#### 执行移动的统一接口

```cpp
// 方向枚举
enum Direction { UP = 0, DOWN = 1, LEFT = 2, RIGHT = 3 };

// 统一移动接口
board_t execute_move(int dir, board_t board) {
    switch (dir) {
        case UP:    return move_up(board);
        case DOWN:  return move_down(board);
        case LEFT:  return move_left(board);
        case RIGHT: return move_right(board);
    }
    return board;
}

// 判断移动是否有效（结果不等于原 board）
bool is_valid_move(int dir, board_t board) {
    return execute_move(dir, board) != board;
}
```

#### 性能分析

| 操作 | 实现方式 | 时间复杂度 | 实际耗时 |
|------|---------|-----------|---------|
| 左/右移动 | 4 次查表 + 位拼接 | O(1) | ~5ns |
| 上/下移动 | 转置 + 4 次查表 + 转置 | O(1) | ~10ns |
| 合并得分 | 4 次查 score_table | O(1) | ~5ns |
| 启发式评估 | 8 次查 heur_table | O(1) | ~8ns |

对比朴素实现（双重循环模拟滑动）约 200-500ns/次，**查表法快 20-100 倍**。这是 AI 能在手机上每秒搜索数百万节点的基础。

## 4. 触控输入

### 4.1 手势识别

```cpp
class Input {
public:
    enum Dir { NONE, UP, DOWN, LEFT, RIGHT };
    enum Act { NOTHING, MOVE, NEW_GAME, UNDO, AI_TOGGLE };

    struct Result { Act act; Dir dir; };

    Result handle(const SDL_Event& e, const Layout& layout) {
        switch (e.type) {
        case SDL_FINGERDOWN:
            sx_ = e.tfinger.x; sy_ = e.tfinger.y;
            st_ = SDL_GetTicks();
            return {NOTHING, NONE};

        case SDL_FINGERUP: {
            float dx = e.tfinger.x - sx_;
            float dy = e.tfinger.y - sy_;
            uint32_t dt = SDL_GetTicks() - st_;
            float dist = std::sqrt(dx*dx + dy*dy);

            // 点击（短距离短时间）→ 检查按钮
            if (dist < 0.03f && dt < 250)
                return check_buttons(e.tfinger.x, e.tfinger.y, layout);

            // 滑动
            if (dt > 400 || dist < 0.04f) return {NOTHING, NONE};
            if (std::abs(dx) > std::abs(dy) * 1.3f)
                return {MOVE, dx > 0 ? RIGHT : LEFT};
            if (std::abs(dy) > std::abs(dx) * 1.3f)
                return {MOVE, dy > 0 ? DOWN : UP};
            return {NOTHING, NONE};
        }

        case SDL_KEYDOWN:
            // 桌面键盘（调试用）
            ...
        }
        return {NOTHING, NONE};
    }

private:
    float sx_, sy_;
    uint32_t st_;
};
```

## 5. AI 冲分引擎

### 5.1 Expectimax

```cpp
class AI {
public:
    int best_move(board_t board);  // 返回 0~3
    struct Stats { int nodes; int depth; float ms; };
    Stats last_stats() const;

private:
    float chance_node(board_t b, int depth, float cprob);
    float move_node(board_t b, int depth, float cprob);
    std::unordered_map<board_t, std::pair<int,float>> cache_;
    int nodes_;
    static constexpr float CPROB_THRESH = 0.0001f;
};
```

搜索过程：
- MAX 层：尝试 4 个方向，取最大值
- CHANCE 层：遍历所有空位 × 2 种 tile，加权平均
- 概率裁剪：累积概率 < 阈值时终止
- Transposition Table：缓存已评估局面
- 自适应深度：空格多浅搜、空格少深搜

### 5.2 启发式

通过行/列查表实现，单次 board 评估 = 8 次查表求和：

```cpp
float eval_board(board_t b) {
    float s = 0;
    board_t t = transpose(b);
    for (int i = 0; i < 4; i++) {
        s += heur_table[get_row(b, i)];
        s += heur_table[get_row(t, i)];
    }
    return s;
}
```

每行的启发式包含：空格数奖励、单调性惩罚、平滑度惩罚、合并潜力奖励、位置权重。
