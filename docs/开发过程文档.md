## 架构决策记录

1. **Bitboard 4-bit 方案** — 每格 4 bit 存 log2(tile)，64 bit 整盘
2. **查表法** — 65536 项预计算，移动 O(1)
3. **Expectimax AI** — 自适应深度 2-6 + 概率裁剪 + 缓存
4. **SDL2 渲染** — 扁平化设计，模仿原版 2048 配色，不用额外图片资源

## 构建与运行

```bash
# MSYS2 UCRT64 环境
pacman -S mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja
pacman -S mingw-w64-ucrt-x86_64-SDL2 mingw-w64-ucrt-x86_64-SDL2_ttf

# 编译
cd 2048-cpp
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build

# 运行
./build/game2048.exe
```
